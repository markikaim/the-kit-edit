THE KIT EDIT — FREE STATIC WEBSITE

1. Create a free public GitHub repository named the-kit-edit.
2. Upload all files and the assets folder from this package to the repository root.
3. In repository Settings → Pages, select Deploy from a branch, main, /(root), Save.
4. Wait for the published link shown in Pages settings.

GitHub Pages is free for public repositories on GitHub Free. A custom domain is optional and usually paid.

Before launch: replace the placeholder contact email in contact.html with your actual business email.

The approved full-page image mockups are included as assets. This is a functional first version of the website, not a pixel-perfect conversion of every mockup; fine-tuning individual service arch imagery remains possible.
